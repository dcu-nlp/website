This research line studies how pipeline neural architectures can improve factuality and control in data-to-text generation. Public papers from the group examine how large language models fit into these pipelines and how multilingual systems can be adapted for shared tasks such as GEM 2024.

The work reflects the group's broader interest in practical, controllable generation systems for real research settings.
