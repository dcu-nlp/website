This shared-task paper presents the group's approach to the GEM 2024 data-to-text challenge. The system combines end-to-end and pipeline neural architectures for English generation and extends the setup to lower-resource languages with machine translation support.

It offers a clear example of the group's multilingual language technology work in a public benchmark setting.
